# 自律台 Windows 使用指南

## 第一次运行

1. 双击 `dist\StudyCheckin.exe`。
2. 程序会自动查找 `D:\.日常\大三上\规划\2028考研_竞赛_课程详细规划.xlsx`。
3. 如果路径不正确，点击“同步与 Excel”区域右侧的文件按钮重新选择工作簿。
4. 程序会选择今天之后最近的计划日期；使用左侧箭头切换日期。

程序读取 `每日执行_2026` 工作表。首次导入只读 Excel，不会修改原文件。

## 每日打卡

- 点击任务右侧“开始”进入计时，同一时间只能运行一项任务。
- 点击“停止”结束计时；不足一分钟按一分钟记录。
- 单次计时超过四小时会要求确认，避免忘记停止造成错误时长。
- 也可以直接在任务旁输入实际分钟数，离开输入框后自动保存。
- 勾选任务左侧复选框表示完成；暂停任务不会计入完成率。
- 在“当日复盘”填写总结后点击“保存并同步”。

## Excel 回写

程序只更新 `每日执行_2026` 中对应日期的以下列：

| 列 | 内容 |
| --- | --- |
| K | 实际小时 |
| M | 状态 |
| N | 当日复盘 |

L 列完成率公式及其他单元格不会被程序修改。如果工作簿正在 Excel 中打开，本次写入会进入等待队列；关闭 Excel 后，程序会在后台重试。

## 托盘与提醒

- 点击窗口关闭按钮不会退出程序，而是缩小到系统托盘。
- 双击托盘图标可重新打开。
- 托盘右键菜单提供“立即同步”和“退出”。
- 可勾选“登录 Windows 后自动运行”。
- 本地提醒时间为每天 07:30、19:00、22:30，以及周日 21:30。

当前提醒依赖 Windows 程序运行。后续接入 CloudBase 和 WxPusher 后，电脑关机时也能通过微信收到提醒。

## 数据与故障处理

本地数据目录为 `%LOCALAPPDATA%\StudyCheckin`。同步失败时先检查：

1. Excel 路径是否正确。
2. Microsoft Excel 是否已安装。
3. 工作簿是否正在其他程序中打开。
4. `每日执行_2026` 工作表及日期行是否仍存在。

需要重新选择计划文件时，使用界面中的文件按钮，不要手工编辑 JSON。
